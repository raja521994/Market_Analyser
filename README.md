# 📈 Indian Equity Investment & Research Advisor

A **local AI agent** specialized in Indian stock market research and investment analysis.

Built with:
- **Ollama** (local LLM)
- **LangGraph** + LangChain
- **Streamlit** (Web UI)
- **yfinance** + DuckDuckGo Search (real-time data)

---

## Features

- Fundamental Analysis
- Valuation Analysis
- Technical Analysis
- Future Price Scenario Modeling (Bear / Base / Bull)
- Risk Analysis
- Sector & Macro Analysis
- Portfolio Analysis support
- Real-time stock data (NSE/BSE)
- Web search for latest news & announcements

---

## Requirements

- Windows / Linux / macOS
- Python 3.10+
- [Ollama](https://ollama.com) installed
- At least 16 GB RAM recommended
